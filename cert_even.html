Projeto Synapse Anemo - UAMExpo 2026

Esse projeto foi desenvolvido durante o 1º semestre de Engenharia de Software para a Avaliaçao 03 para a ExpoUAM 2026, o escopo do projeto envolveu a criação de uma aplicação web interativa usando Phyton (tanto no Frontend quanto no Backend), N8N, Google Gemini IA (ChatBot), Open-Meteo e ESP32. O objetivo é criar um software que mede a temperatura em Tempo Real e exibe no display do ESP32

A forma de acessar informaçoes no app é atraves do Chatbot que responde e interage com o usuario, o Chatbot chamado de Kaze-01 busca os dados da API Open-Meteo, converte em JSON e retorna no chat além de dar dicas sobre o clima se precisa se hidratar ou se precisa levar um casaco além de outras interações como uma representação gráfica do Kaze-01 como um avatar estilo Tamagochi.

Os dados do clima são exibidos no display do ESP32, incluindo informações como chuva, temperatura em graus Celsius, umidade relativa, velocidade do vento e pressão atmosférica.

O periférico também se conecta a uma bateria pilha recarregável com entrada para cabo Tipo C, permitindo que o dispositivo seja portátil e utilizado em diferentes ambientes, como em atividades ao ar livre ou em locais sem acesso a energia elétrica.

O case de mercado seria implementar sensores de temperatura para escritórios, fazendas e fabricas para identificar problemas nos circuitos em tempo real como superaquecimento ou temperatura abaixo do nor para evitar acidentes e prejuizos.

O projeto foi apresentado na UAMExpo 2026 como projeto de semestre da matéria de Modelagem de Circuitos Elétricos, onde recebeu feedback positivo pela inovação e aplicabilidade prática tirando nota máxima.
